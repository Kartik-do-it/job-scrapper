# IT Job Tracker

This project scrapes entry-level software engineering jobs and adds newly found roles to a Google Sheet. The `Applied?`, `Applied Date`, and `Notes` columns make it easy to track your application progress.

See [Google Sheets setup](GOOGLE_SHEETS_SETUP.md) for the required Google Cloud and GitHub Actions secrets configuration.
